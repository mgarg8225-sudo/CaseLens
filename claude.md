# TinyFish Instructions

Use TinyFish for web search, fetching web pages, and browser automation when needed.

- Use the configured TinyFish tools when available.
- Keep API keys and other secrets in environment variables. Never hardcode or print them.
- Before using TinyFish, check which tools are available in the connected agent.
- If TinyFish is not connected, explain the setup issue instead of pretending it worked.
